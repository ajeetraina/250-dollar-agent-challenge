# 💡 Starter Ideas

Stuck on what to build? Here are concrete starting points per track. Steal, remix, or ignore.

## 🌙 Night Shift
- **On-call responder** — watches an alert channel; on a page, pulls logs, forms a hypothesis, and opens a draft PR. You wake up to a fix to review.
- **Dependency gardener** — overnight: bump deps, build, run tests, open green PRs only.
- **Long crawl** — scrape + clean a large dataset that would otherwise hog your laptop for hours.

## 🔐 No Keys Allowed
- **GitHub manager** — triage issues, label, and open PRs through a proxied token; prove `env` inside the sandbox has no raw token.
- **Paid-API agent** — call a metered API successfully while showing the key never entered the VM (check `sbx policy log`).

## 🔌 Tool Master
- **Daily briefing** — calendar + email MCPs → a morning digest and a prioritized to-do.
- **DB detective** — a database MCP to find and fix a slow query, with before/after timings.
- **Research chain** — web-search MCP + notes MCP producing a cited summary.

## 👥 The Crew
- **Mini software team** — architect / implementer / reviewer, each its own sandbox on its own branch.
- **Fan-out migration** — one agent per package/service, all running at once, then a synthesizer merges.
- **Competing solvers** — N agents attempt the same task; you pick the winner.

## 🧰 Kit Maker
- **One-command kit** — `./run.sh` sets secrets + policy and launches a domain-tuned agent on a fresh machine.
- **Custom template** — a `sbx save`'d image preloaded with your toolchain so others start in seconds.
